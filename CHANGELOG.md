# Website Project - Development Log

## Project Overview
This website includes a lightbox gallery, validated contact forms, a digital food ordering store, and SEO optimization.

## Changelog / Development Timeline

### October 12, 2026 - Added Lightbox Feature
- Implemented JavaScript lightbox for image gallery
- Users can click on images to view enlarged version
- Added close button and navigation functionality
- Files updated: `script.js`, `gallery.html`, `style.css`

### October 14, 2026 - Form Validation
- Added JavaScript validation for contact form
- Added JavaScript validation for inquiry form
- Validation checks for: empty fields, valid email format, minimum message length
- Removed HTML `required` attribute and replaced with custom JS error messages
- Files updated: `script.js`, `contact.html`, `inquiry.html`

### October 18, 2026 - Digital Store / Food Ordering System
- Created digital store section for food ordering
- Implemented product listing with add-to-cart functionality
- Added cart summary and total price calculation
- Customers can place orders through the website
- Files updated: `store.html`, `script.js`, `style.css`

### October 22, 2026 - SEO Best Practices
- Added meta title and meta description to all pages
- Added alt text to all images
- Implemented semantic HTML tags (header, nav, main, footer, section)
- Created sitemap and improved heading hierarchy (H1, H2, H3)
- Optimized page loading and mobile responsiveness
- Files updated: All HTML files, `style.css`

### October 25, 2026 - Final Testing & Deployment
- Tested all features across different browsers
- Validated HTML and CSS
- Deployed website to Netlify
